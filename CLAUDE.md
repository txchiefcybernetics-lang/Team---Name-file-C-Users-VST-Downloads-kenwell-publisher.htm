# Tradexpress Project Context & Rules

## Project Overview
- **Name:** tradexpress-app
- **Purpose:** Next-gen trading application & analytics tool.

## Build & Test Commands
- **Development Server:** `npm run dev`
- **Build Production:** `npm run build`
- **Run Tests:** `npm test`

## Environment & Secrets
- Never commit `.env` or sensitive API keys.
- Required credentials: Supabase URL/Anon Key, Bitbucket SSH keys.

## Code Style & Guidelines
- Use TypeScript for all React/Next.js components.
- Follow functional programming standards and clean component structure.
- Store static design/architecture documents in the `/docs` directory.
