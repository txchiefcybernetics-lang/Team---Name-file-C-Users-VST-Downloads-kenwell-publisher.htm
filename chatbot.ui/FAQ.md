## Getting Started

### Q: What is TxBot?
**A:** TxBot is an AI-powered token management assistant that integrates with TradeX ecosystem services. It provides real-time support for customs brokerage, trade assistance, compliance management, and marketplace operations.

**A:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+, and any modern mobile browser.

### Q: Is TxBot available on mobile?
**A:** Yes! The chatbot is fully responsive and works on smartphones, tablets, and desktop browsers.

## Technical Support

### Q: I'm getting error messages. What should I do?
**A:** Try these steps:
1. Clear your browser cache (Ctrl+Shift+Delete)
2. Refresh the page (F5 or Cmd+R)
3. Try a different browser
4. Check your internet connection
5. Ensure JavaScript is enabled

### Q: The chatbot isn't responding. Why?
**A:** Common causes:
- Backend server is down - contact support
- Network connectivity issues - check your internet
- Browser console errors - open F12 and check Console tab
- API timeout - try again in a few moments

### Q: How do I report a bug?
**A:** Open a GitHub issue with:
- Steps to reproduce
- Browser and OS information
- Screenshots or error messages
- Expected vs. actual behavior

### Q: Can I customize the chatbot appearance?
**A:** Yes! Edit these files:
- `styles.css` - Colors, fonts, layout
- `index.html` - Text content
- `script.js` - Responses and logic

### Q: How do I integrate my backend API?
**A:** Follow the API Integration Example in [README.md](README.md#api-integration-example). Update the fetch URL to point to your backend service.

### Q: What's the response time for API calls?
**A:** Typical response times:
- Demo (local) - <100ms
- Production (API) - 200-500ms
- Heavy load - up to 2 seconds

## Customs Brokerage

### Q: What documents do I need for customs clearance?
**A:** Standard requirements include:
- Commercial Invoice
- Bill of Lading/Airwaill
- Packing List
- Certificate of Origin
- Import License (if applicable)
- Insurance Certificate

Ask TxBot: "What documents do I need?"

### Q: How long does customs clearance take?
**A:** Typical timeframes:
- Pre-clearance: 2-4 hours
- Standard clearance: 24-48 hours
- Complex cases: 3-5 days
- Ask TxBot for your specific shipment

### Q: What are common tariff classifications?
**A:** Ask TxBot with your product description:
- "Classify my product"
- "What's the HS code for electronics?"
- "Tariff rate for textiles?"

### Q: How are duties calculated?
**A:** Duties depend on:
- Tariff classification (HS code)
- Country of origin
- Product value
- Trade agreements
- Special regulations

Use TxBot: "Calculate duty for my shipment"

### Q: What's the difference between FOB and CIF?
**A:** 
- **FOB** (Free on Board) - Seller covers shipping to port; buyer covers thereafter
- **CIF** (Cost, Insurance, Freight) - Seller covers shipping and insurance to destination port

Ask TxBot for specific trade term explanations.

**A:** Try:
